# APEX Global Education — Phase 1 Public Website Prototype

## PROJECT OVERVIEW

Build a premium, modern, responsive public-facing website prototype for a study-abroad education consultancy called:

**APEX Global Education**

APEX is an established study-abroad consultancy with approximately 15+ years of experience helping students, especially students pursuing higher education abroad after B.Tech and other undergraduate degrees.

This is **PHASE 1 ONLY**.

The goal of this phase is to create a polished **public marketing and lead-generation website**.

Do NOT build the private student CRM, admin dashboard, authentication system, student portal, application tracking system, document management system, or internal consultancy management features in this phase.

The website should feel like a consultancy that has been operating successfully for many years, not like a generic template or a newly created startup.

Use realistic **MOCK DATA** throughout the prototype. Clearly structure the data so it can easily be replaced with real client information later.

---

# PRIMARY OBJECTIVE

The website should accomplish four things:

1. Establish trust and credibility.
2. Clearly explain APEX's study-abroad services.
3. Help students discover suitable study destinations and understand the process.
4. Convert visitors into consultation/enquiry leads.

The primary CTA throughout the website should be:

**Book a Free Consultation**

Secondary CTA:

**Explore Study Destinations**
